Download **VHVN-Setup.exe** below. Run it, then open **VHVN** from your desktop or Start menu. The app guides you through game setup on its first launch; afterward it connects when Fata Morgana opens.

No ZIP extraction, command files, or developer tools are needed to use this release.

Changes in 0.2.1:

- One Windows installer with desktop and Start menu shortcuts.
- Automatic first-time game setup and waiting for the game to open.
- Larger installer text and a recognizable book/speech icon.
- Windows uninstall removes the helper's verified game extension while keeping saves, settings, and backups.

Includes dialogue, supported menu/backlog/choice narration, speaker-name hover, typed or recorded shortcuts, and spoken helper controls from the previous preview.

Requires Windows 10/11 x64, installed Windows speech voices, and the verified English Steam build of The House in Fata Morgana. This remains a preview; full-game and assistive-tool coverage are not guaranteed. The EXE is currently unsigned.

The **Source code** archives below are for developers. Players should choose **VHVN-Setup.exe**. SHA256SUMS.txt contains the installer checksum.
